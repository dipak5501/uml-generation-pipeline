What this site is

This .github.io page is the public project home. The interactive Streamlit + FastAPI application needs a Python host (Render Blueprint from the same repo) — GitHub Pages cannot run those services.

After you deploy Render, set the homepage or edit this page’s Open live app link to your uml-pipeline-ui URL (for example https://uml-pipeline-ui.onrender.com).

Pipeline

One path from text (or source code) to verified diagrams.

Requirement / code → tech spec → PlantUML → validate / repair → render gate → 3 VLMs → composite S + majority A → dataset if A=1 and S≥3

Run it

Local: make run → http://127.0.0.1:8501 · Cloud: Render Blueprint · see docs/deploy.md.
